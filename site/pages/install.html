日常润色：安装 Skill

下载 editorial-guard-zh-v0.2.0.zip，解压后放入宿主技能目录。Codex 项目使用 .agents/skills/；WorkBuddy 使用对应平台包。

请用 editorial-guard-zh 润色下面的中文，
保留全部事实和条件，保持原来的语气，只返回候选正文。
[粘贴原稿]

无需另配 API 密钥，但使用宿主的模型额度。结果为候选，尚未独立验收。

重要文件：安装 CLI

Python 3.11 或更新版本，下载 wheel 后运行：

python -m pip install editorial_guard-0.2.0-py3-none-any.whl
editorial-guard doctor

准备模型配置、密钥环境变量和任务上下文，即可验证已有候选：

editorial-guard verify original.md --candidate candidate.md --context context.json --config config.json --mode both --judge glm --sidecar review.json --receipt receipt.json

通过后可使用 finalize 受控保存；只做规则 lint 时，退出码 2 表示尚未完成语义验收。
