# 本地交付验收

软件使用说明许可：MIT。验收只约束本工具的受控本地写入。

语义校验结合原文、资料、任务阶段、模式、风格配置和独立裁判。凭证绑定输入及候选 UTF-8 字节哈希、完整任务上下文、供应商配置、规则版本、run_id 和 turn_id。finalize 必须使用与校验相同的 --context、--mode 和 --config。任何修改都会使旧凭证失效。

使用 rewrite 或 pipeline 的 --output candidate.md 保存精确 UTF-8 字节，避免 PowerShell 重定向改变编码或换行。验证已有文件时逐字节读取并解码，保留 CRLF。正文与 sidecar 诊断分离；失败时正文保留原文，不给失败候选颁发通过凭证。

ReceiptStore 使用本机私有密钥签名，防止候选内容伪造通过结果；它不防御完全控制当前用户账户并可读取密钥的攻击者。候选与目标必须位于指定 root，拒绝父目录跳转、符号链接与 Windows reparse point。写入采用同目录临时文件、重算哈希和原子替换。文件系统攻击者可并发替换整个目录树的情形超出当前保证。

Stop hook 是对登记交付物的快速检查，不调用全部模型。它不能撤销已发生的外部副作用。未信任或未触发的原生 hook 不计为成功；外部受控流程的测试与原生事件测试分开报告。

凭证保存原稿哈希以供追溯；finalize 不重新读取外部原稿文件，也不持续监控外部资料。源资料以本次传入的 context.source_bundle 为准。外部资料更新后应更新上下文并重新验收，不能把原稿哈希的记录误认为文件监控。
