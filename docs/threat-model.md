# 威胁模型与交付限制

软件许可：MIT。

待评正文是不可信数据，可能包含评分操纵或工具调用指令。模型评审无工具权限，正文通过独立系统约束和结构化输入提供；分隔符本身不是充分安全保证。程序测试覆盖提示注入和无依据增写，不能证明抵御所有对抗输入。

工具包和Skill不含benchmark答案；solver输入使用字段白名单。数据文件分目录不等于安全隔离，尤其不能防止同用户主动读取全盘。锁定集在冻结评测完成前不进入Git、站点、下载包或CI artifact。公开之后不再视为未见测试。

签名验收凭证绑定候选字节hash、规则、配置、run和turn。finalize在授权目录内拒绝路径越界、符号链接与reparse点，重新核对候选并原子替换目标。签名密钥属于当前本地使用者；这不防御已经完全控制该用户文件与进程的攻击者。

项目Stop hook只检查明确登记的正文文件。它可请求继续执行，不能撤回已显示文本。PostToolUse不能撤回已发生副作用。任意shell、第三方发布工具、直接上传或流式消息绕过wrapper时，不在严格交付保证范围。

故障、超时、未知模型、无凭据与未完成验证均不通过。hook发生异常可能只向宿主发出unchecked提示，严格保证来自受控finalize。项目工具不发布用户文章、不发邮件、不连接外部业务系统。
