# 输出变化、运行时间与调用成本

许可：CC BY 4.0。汇总脚本使用 MIT。本文规定离线描述性指标，不改变正式实验的冻结提示、接受判据或运行时。

保存的正式单元可用以下命令重算；只有明确给出 `--work-dir` 时才读取该目录中的本地请求账本。脚本不调用模型，不需要凭据。

```console
python scripts/summarize_experiment.py --experiment .eg/experiments/formal --input datasets/StyleBench-ZH/samples.jsonl --input datasets/DeliveryBench-ZH/samples.jsonl --work-dir .eg --output reports/operational-metrics.json
```

缺少原稿时，长度与文本变化指标保留缺失；没有账本时，费用和时间不补为零。注册清单存在时，报告注册量、终态记录量和未取得终态的数量。缺失执行不插值为模型质量失败。同一单元有多次执行时使用最高执行序号；同序号出现冲突记录会停止汇总，要求检查原始证据。

|指标|口径与边界|
|---|---|
|输出长度变化|候选与原稿的Unicode码点差和比率，包含标点、空白和格式字符。空输出长度为零，缺失输出没有长度；原稿为空时比例未定义。不是新的字数合格阈值。|
|原文保留|候选与原稿逐字相等的单元数。保留原文不自动等于有效成功。|
|无需修改文本放行|可比较文本中，现有证据有效的裁判均称原稿无需修改，候选未变，且裁判对候选保真、任务要求、无严重新问题及适用过程要求均判通过。|
|无需修改文本上的误改信号|现有有效裁判均称原稿无需修改，候选确有变化，并且至少一票判变差、保真失败、任务失败或新增严重问题。它是模型信号，不把所有改动都视为有害。|
|新增严重问题信号|至少一份证据有效的裁判记录将no_new_serious_issue判为false。与候选保真失败及同裁判B0对照的新增损伤指标分开。|
|不确定和无效证据|保真/任务要求为uncertain的单元另计；文本证据未验证或明确无效的票不参与质量比率。|
|调用成本|收集编辑、选择、修复与独立裁判的已保存请求引用，并纳入这些任务键下已记录的失败重试。估计费用和实际费用分开，各币种分开。|
|请求运行时间|账本ended减started。报告已关联唯一请求的总时间和中位数，未结束或无记录的请求不补值。它不包含预留并发名额前的排队，也不等于完整实验单元延迟。|

所有指标按供应商、方法、模式、套件、风格配置和自然/受控路线分层，没有将两个套件相加为通用写作分数。家族聚类数按source_group_id去重；同源变体、重复运行与裁判票数仍有关联，这一计数不证明语义独立性。正式成对bootstrap另用冻结的家族级方法计算，模型严重度均值只作有序等级的描述。

缓存引用在各层内去重，整个实验的已关联请求集合也单独去重。同一个请求可能服务多个层，不能相加各层费用得到总账单；失败后成功的同任务重试也计入所关联费用。

如果一个单元的请求全部失败，而旧记录没有保存请求ID，该费用可能无法归属到单元。脚本明确将费用标为部分归属，不能把这一小计当成完整方法成本。完整账本总量应另行报告。真实供应商账单、客户端内部调用和未记录的全流程时间仍为未知，不以当前实现哈希或估计金额补造历史证据。

部分单元仅有一份有效裁判票，相关指标反映当前可用模型意见；无需修改参考票数和分歧计数随指标报告。结果不能冒充两票齐备或人工验证。执行失败、缺失输入和未运行单元继续保留在覆盖表中，不因离线统计而变为成功。
