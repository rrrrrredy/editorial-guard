# 检测与定位指标

许可：CC BY 4.0。代码示例与评分器实现使用 MIT。

离线函数 `editorial_guard.scoring.detection_report(samples, predictions)` 接收样本及检测结果。它使用样本的自动标注记录作为比较参考；这些记录不进入运行时编辑器或保真检查器。检测者自己的标注不能作为自己的参考。

文档级结果分别比较 `style_problem` 和 `process_problem`，报告 TP、FP、FN、precision、recall、F1。不同套件、检测供应商和参考供应商保持分开。参考供应商意见不一致时保留多组比较，不多数投票造出真值，也不将不同裁判票数当作独立任务。

片段级结果有两种口径：

- 精确片段：文档、任务归属和起止位置全部相同才匹配。
- 字符覆盖：按文档和任务归属合并覆盖位置；重叠或重复片段不能重复得分。

位置使用 Unicode code point，右端不包含在片段中，不预先归一化原稿。积极修改片段仅包括 `rewrite` 和 `remove`；`preserve` 与 `review` 不按确定需要修改的正例计算。该口径必须与报告一起保留。

分母为零返回 `null`，不自动记为满分。没有独立参考、参考认为题目无效、语言不在支持范围、检测调用失败分别计数。缺失参考不补标签，失败调用不插值。报告同时保留注册数与成功响应数，避免只展示有分数的部分。

这些指标表示相对于指定模型标注的一致程度，不是人工验证后的客观正确率。单家族结果只作局部描述；同源变体、重复运行与多裁判票数不能扩大独立家族数。调用者应把重复检测放在明确区分的运行批次中；同一批次出现重复的供应商和实例组合会被拒绝。
