# 公开数据入口

先按任务家族阅读，再查看标签和底稿。同一家族的正常模型输出与受控变体不是两个独立任务；正常输出也不是人类文章。

| 需要 | 入口 |
| --- | --- |
| 按任务、文体和争议浏览全文 | [在线家族浏览](https://rrrrrredy.github.io/editorial-guard/datasets.html) |
| 了解两套数据的来源、许可与局限 | [StyleBench-ZH 数据卡](StyleBench-ZH/DATASET_CARD.md) · [DeliveryBench-ZH 数据卡](DeliveryBench-ZH/DATASET_CARD.md) |
| 下载完整记录、按家族提取底稿与标注 | [数据使用说明](../docs/dataset-use.md) |
| 看改稿后的实际效果 | [完整文章案例](../examples/full-articles/README.md) · [结果导航](../reports/README.md) |

公开范围为 482 个源家族、964 条实例。页面按需读取固定 v0.1.1 的完整记录，并保留原始 JSON。文风、交付旁白和原稿保真分别展示；模型分歧不合成为一个笼统分数。事实底稿、保护片段和标注属于研究者视图，不能整体作为编辑器的评测输入。

数据版本和历史结果未因软件更新而重算。此目录的 JSON 预览、数据卡及质量索引保持各自用途，无需新增数据库服务。
