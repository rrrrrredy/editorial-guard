# Changelog

## 1.0.0

- Establish the direct Skill entrypoint and documented CLI/configuration usage as the stable 1.x interface; retain separate dataset and experiment versions.

- Add full-article comparisons and readable model evidence, disagreements and preservation reasons to the static site; keep frozen data and results at 0.1.1.

- Add content-led guidance for repetition, paragraph relationships, modifiers, genre and author voice to the host Skill and runtime editing prompt, maintained from one source. Preserve useful synthesis and narrative recurrence, and retain the author's degree of certainty in either direction.
- Keep direct candidate delivery, optional no-op and existing independent validation boundaries; no new keyword rules or dependencies.
- Preserve two complete synthetic articles, six raw host candidates and separate revised examples. The small comparison does not establish an advantage over a brief prompt.
- Fix numeric matching that restarted inside an identifier such as V249 and reported its suffix as a number; retain conservative semantic-review signals for numeric and qualifier changes.

## 0.2.0

- Added a portable Chinese editing Skill and platform packages.
- Clarified candidate editing, independent verification and controlled local delivery.
- Added common Markdown structure checks and author-voice context bound to receipts.
- Preserved the 0.1.1 dataset and historical benchmark results; no new model evaluation.



## 0.1.1

- Retry transient Windows file locks during atomic snapshot replacement, with a bounded wait and preservation of the previous snapshot on failure.
- Publish the same benchmark records and measured results as 0.1.0; no model experiments or annotations were rerun for this fix.

## 0.1.0

- Separate Chinese style editing and delivery-language checks with shared source-fidelity validation.
- Persistent provider accounting, bounded repair, exact-text protection and signed local finalization.
- Independent project skills, reversible Codex hook adapter and explicit host capability boundaries.
- Versioned benchmark protocols, model-generated calibration evidence, and a static documentation and sample browser.

Data counts, completed experiments and platform validation are reported separately in the release evidence. This version does not claim human-level writing quality or global control over external publishing tools.
