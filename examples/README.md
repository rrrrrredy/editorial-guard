# 改写与保留示例

以下为教学例子，不是新模型实验或优胜证明。

## 去掉空话，保留独立信息

原稿：这次更新彰显了团队的创新精神。它新增导出、搜索和批量重命名。离线编辑计划在下一版推出，目前尚未完成测试。

候选：这次更新新增导出、搜索和批量重命名。离线编辑计划在下一版推出，目前尚未完成测试。

保留了三项功能、未来计划和测试状态；不新增时间、性能数据或用户反馈。

## 已经清楚，可以不改

原稿与候选：先保存文件，再关闭窗口。未保存的修改会丢失。

## 应拒绝的改写

原稿：现有材料没有提供测量结果。

错误候选：该团队从未测量过性能。

问题：材料未提供不等于工作没有发生。更多保留边界见技能的 references/editing-boundaries.md。公开实验失败与裁判分歧另见 reports/results.md。
