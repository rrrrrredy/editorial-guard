# 教程：删同义说明，留操作复述

[完整原文](original.md) · [完整示范稿](edited.md) · [全文并排](../../../reports/article-study-20261027/artifacts/tutorial.html)

来源为 DeliveryBench-ZH 的 `main-0305-natural`，已公开验证分区中的虚构项目教程，原记录的标注状态是 `disputed`。本轮没有把争议标签当作答案，也没有把 `natural` 当成人类文章。原文 1853 字符，示范稿 1681 字符；篇幅变化不用于判定优劣。

## 真正值得改的部分

第二节把“活动持续14天”“关于14天之后是否还有场次，资料的状态是尚未公布后续场次”收紧为“活动持续14天，后续场次尚未公布”。后文保留对外表述原句，以及不得补出下场时间、地点或名额的规则。读者能先看到本期周期和后续状态，不必先绕过一层状态解释。

第三节保留“3份附件尚待核对”和“未核对的附件不得用于扩大现有结论”，删除紧接其后的“这3份附件的数量是待核对状态，不是已完成核对的数量”。该句只再次解释前句的待核对状态；后面的标识、核对后再决定使用、对外引用前核对版本号都保留。

第六节将内部分工与非外部审计放在同一句，不再单独用一句重复“这一安排是内部分工”。第七节把发现异常时的记录动作提前，随后写复核前后的处理方式，仍保留原始数值、单位、观察条件、异常标识和调整依据。

## 应该保留，或不值得改

- 文末九项清单与前面解释有重合，但用途不同：正文帮助理解，清单帮助执行。因此十个章节、九项清单及其顺序保留，清单正文也保持原文。
- “这不是真实新闻，而是一个虚构项目情境下的操作说明”在排除来源误解。规则会把它报为 `不是…而是` 候选，示范稿仍保留原句。换个顺序并没有明确的阅读收益。
- “报名人数不等于可入场人数”和“更新频率不代表工作发生的频率”都是必要概念区分。“原始数值、单位和观察条件”也是有实际内容的并列。
- 第八节整段保留原文，包括“可选”这个带引号的原词。这段为参与者解释空缺、零结果及非必填的关系；本轮先保留清楚的定义，不为压缩继续改。
