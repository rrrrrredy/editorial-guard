# 编辑边界与例子

例子为教学材料，未包含隐藏资料；不作为模型效果评测。

| 情况 | 可以怎样改 | 必须保留 |
|---|---|---|
| 这次更新彰显创新。它新增导出、搜索和批量重命名。 | 删除空泛赞美，保留功能句 | 三项功能全部保留 |
| 我们正在对系统进行全面测试，计划周五调整配置。 | 我们正在全面测试系统，计划周五调整配置。 | 正在与计划，不写成完成 |
| 该问题被认为可能与缓存有关，原因尚未确认。 | 可原样保留 | 不补造判断者，不把相关变因果 |
| 甲组核对数据。与此同时，乙组测试导出。 | 甲组核对数据，同时乙组测试导出。 | 同时发生，不改成先后 |
| 现有材料未提供测量结果。 | 可原样保留 | 不写成从未测量或不存在结果 |
| 我有些期待，也有些犹豫，还没决定是否继续。 | 可原样保留 | 不替作者确定立场 |
| 下面我先核对资料，再给出结论。 | 最终成稿中无实际内容的预告可删 | 计划或进展任务需要时保留 |
| 数量不变、顺序不变、权限不变。 | 可原样保留 | 三项独立约束，四字节奏不是错误 |
| 这个预算没有支出。换句话说，这笔预算还没花出去。 | 在普通工作报告中可保留第一句；教学解释可保留两句 | 判断是否重复要结合读者用途 |
| 计划采购的、仅在断网时供值班员查阅记录的终端尚未通过测试。 | 计划采购的终端尚未通过测试。这类终端仅供值班员在断网时查阅记录。 | 计划状态、使用对象与条件；不能写成终端已投入使用 |
| 本节解释保存方法，文末再给出保存步骤清单。 | 解释与清单可以同时保留 | 理解原理和现场操作是两种用途 |

引文、术语、必要限定、合理对比和有用途的礼貌语不因模式命中而删除。没有事实依据时，“更具体”不是编辑目标。作者声音通过表达体现，不添加虚构经历。
