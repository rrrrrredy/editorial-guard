# 完整文章编辑观察：具体改法补齐了，稳定收益尚未证明

2026-10-27，基于本地基线 `2be3a97`。本轮改进的是全文理解后的编辑指导，同时保留直接宿主改稿和原有保真边界。两篇合成稿、三种方法、六份首次候选的比较没有证明新 Skill 稳定优于简短提示。两份最终示范包含观察后的继续修订，不能计入首次候选成绩。

具体方法集中在 `protocol.EDITING_GUIDANCE`，由 `scripts/sync_prompts.py` 同步成统一 Skill 的[内容编辑说明](../../skills/editorial-guard-zh/references/editing-craft.md)、运行提示及两个专用 Skill 的运行规则。标准保留判断口径，运行指导负责改法，减少手写副本漂移。作者声音从句长、词语和语气扩展到解释方式、组织方式、态度和有作用的修辞；没有作者样本时依原稿，不凭空建立作者画像。

新增方法独立写作；没有新增模型依赖、词句规则、总分或发布流程。本轮观察完成时版本号未变；后续产品发布包含这些修改，历史 `reports/results.md`、冻结指标和数据记录保持原样。本轮不是原实验的新增单元。

## 实际看到了什么

| 教程解释与末尾清单 | 都保留 | 都保留 | 都保留 | 这次没有把有用复述全删；收益不专属于新方法。 |
| 受保护引词 | 移除“可选” | 另移除两处更新状态引词 | 移除“可选” | 三者都违反本轮原样保留要求；语义大体相近不等于满足编辑约束。 |
| 教程的禁止与条件范围 | 未发现新增指导中的同一改法 | 有压缩 | “不能据此自行补记”、省去合并限制的显式条件 | 新指导不能保证保真，发现的问题必须撤回。此表不宣称其他候选完整通过。 |

观察后，将内容指导中的重复处理进一步写实：同一意思的不同说法不全是独立信息；在解释最充分的位置保留判断，其他位置只留增量；教程解释与清单可因用途不同同时保留。此修改没有再跑一轮模型比较，不能把六份输出当成最终提示的验证结果。

两份 `edited.md` 是后续示范：工作报告重排同一节内的记录规则，集中结论限制；教程撤回范围变化、恢复引词，并原样保留第八节及文末清单。它们用于展示编辑取舍，不能把主编辑继续修订的效果记给自动流程。具体前后片段、数字条件清单、不值得改的句子均在两个案例说明中。

## 程序检查如何解释

沿用 `lint_text`、`verify_edit` 和既有结构保护，仅增加一个离线重放与全文展示脚本。最新结果见 [checks.json](artifacts/checks.json)，全文对照见[工作报告](artifacts/work-report.html)和[教程](artifacts/tutorial.html)。

复核发现原数字正则会在 `V249` 匹配失败后，从后两位重新开始，误取 `49`。示范报告只保留一次完整版本号，原程序因此报数字变化。现在阻止在字母、数字或下划线之后重新起匹配；并未放宽数字出现次数或限定词检查。版本号的完整含义仍应由语义复核覆盖，这个局部修正不是通用标识符验证器。

两份示范的结构变更列表均为空，教程受保护片段均保留。报告仍有 `qualifier_change_requires_review`；教程另有 `numeric_claim_changed`，因为删去同一数字的重复解释会改变提及次数。当前返回仍是 `fail`，没有为了展示通过而改变结果。程序信号不能区分每次词数变化的语义，所以本轮保留警报并用案例逐项说明，没有生成独立验收凭证。

`checks-before-identifier-fix.json` 保留中途发现问题时的观察。当时数字修正和最终教程修订均未完成；它与最新文件不是只改变正则的控制实验，也不能拿差值衡量编辑效果。

## 验证支持与不足

本轮支持的范围：新增编辑指导已进入直接宿主入口和运行提示；两篇完整文章有可追踪的局部改进与撤回记录；既有检查能发现部分保护损伤；具体版本号误识别已修正。本地必要检查与失败处理见[验证记录](validation.md)。

本轮不支持：新 Skill 稳定优于简短提示、真实读者更喜欢、通用作者声音保持率、专业术语处理优势、跨文体或跨宿主效果、万字长文组织能力。两篇都是说明性合成稿；过长修饰只补了教学例子，没有对应完整文章效果证据。没有新增多供应商独立验收，也未导入真实平台验证。示范稿依然可能有读者认为无益的压缩，欢迎对照完整原文判断，但不称为人工认可。
