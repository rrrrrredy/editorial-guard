# 文风规则

四维问题严重度分别记录：模板依赖、信息表达效率、行文连贯性、场景匹配。0 无问题，1 局部轻微，2 反复但主要信息可读，3 显著妨碍理解或场景，4 主体被机械表达替代。每次判定须有原文证据；不汇总成AI来源概率。

保真不通过则编辑不能算成功。必要来源、否定、条件、因果和未知事项均要保留。process 片段的清理主要归过程任务，不能重复奖励。general-zh 不强制统一作者风格；editorial-zh 偏好完整自然段、具体判断、完整论证，不强行口语化。

具体编辑方法见[运行规则](runtime-rules.md)中的内容组织指导。候选词句只能提供局部线索；通读全文后判断是否有无增量的重复论证、依据远离判断、修饰遮住主干或不合读者用途的表达。比较、排比、术语和重复提醒各自可能承担必要功能，不能用删除数量作为收益。本文记录评分口径，运行规则负责改法，不另设一套分数。
